# Mini Project 1

A Python-based mini project for calculating theoretical bond prices using zero-rate curves.

## Features

- Calculates theoretical bond prices using zero-rate curves
- Uses cubic spline interpolation for zero rates
- Calculates discount factors using semi-annual compounding
- Computes the present value of future bond cash flows

## Requirements

- Python 3.8+
- pip
- NumPy
- SciPy

## Installation & Usage

Clone the repository:

```bash
git clone https://github.com/anurag-iisc-25564/bond-pricing-model.git
cd miniproject1
